# done灯 macOS 公测版

这是 done灯 的公开下载仓库，只发布已签名并通过 Apple 公证的 macOS 安装包，不包含应用源码。

## 下载

前往 [Latest Release](https://github.com/LearnPrompt/done-lamp-releases/releases/latest) 下载 `done-lamp-0.3.4.dmg`。

## 安装

1. 双击 `done-lamp-0.3.4.dmg`。
2. 把 `done灯.app` 拖到“应用程序”。
3. 从“应用程序”打开 done灯。

安装包支持 Apple Silicon 和 Intel Mac，需要 macOS 14.0 或更高版本。每个 Release 都会公布 SHA-256 校验值。
